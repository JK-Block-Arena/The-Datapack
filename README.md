## 如何使用

1. 前往 [Releases](https://github.com/JK-Block-Arena/The-Datapack/releases) 下载最新版数据包（`.zip`）。
2. 进入《方块竞技场》存档，打开 `datapacks` 文件夹。
3. 删除原有的 `pvp3` 文件夹，将下载的数据包放入。
4. **重要**：请**先完成上述操作**，再进入存档/启动服务器；如果已经进入，请退出后重进。
5. 进入游戏后依次执行：
   - `/reload`
   - `/function #debug_init`（重置配置）
6. 打开「神の面板」：`/function #debug`

> 💡 想自己动手修改？可参考 [这个教程](https://www.bilibili.com/read/cv17401279/)。
